# T001 试派发：环境核查（只读）

## 目标
确认你（Codex）能通过 Orca 接收任务、访问本仓库并回报结果；摸清执行环境，为后续开发和作图任务做准备。

## 开工前必读
`AGENTS.md`、`docs/WORKFLOW.md`、`docs/ART-STYLE.md`。读完后，在回报里用三五句话概括你理解的分工、作图审图关卡和画风约束。

## 要做的事（全部只读，不修改任何文件，不提交、不推送）
1. 报告运行环境：操作系统（Windows 原生还是 WSL）、当前工作目录、`git rev-parse --abbrev-ref HEAD`、`git log --oneline -1`、`node --version`。
2. 运行 `npm run check`，记录结果摘要。
3. 运行 `npm test`，记录通过数、失败数及每个失败用例的文件:行号和报错首行。已知 `tests/layered-art.test.cjs:36` 报 `Invalid pose body`，这一项失败是预期的，本任务不修复。
4. 说明你是否具备内置的图像生成/编辑能力（不调用外部图像 API）。只回答有没有、叫什么名字，**本任务不要生成任何图片**。
5. 说明能否运行浏览器测试（Playwright/Chrome 是否可用）；不可用就如实说明，不要安装任何东西。

## 允许修改的文件
无。

## 退出码
`npm test` 或 `npm run check` 非零退出不算本任务失败，如实记录结果就是交付物。只有无法访问仓库或无法运行命令时，才算任务失败。

## 交付
用 `worker_done` 回报上述 1–5 项的结果及命令输出摘要。
