# 第一级15篇浏览器完整试用

当前版本：`level1-complete-15-20261027`。正式文稿仍来自用户指定15篇，集成不修改故事措辞。普通书架现在直接显示这15篇，原有单独审核入口仍保留。

## 打开和试用

1. 双击项目根目录“打开管理后台.cmd”，保持启动窗口运行。
2. 阅读端：<http://127.0.0.1:4180/>；后台：<http://127.0.0.1:4180/admin>，本机密码 `111`。
3. 在“小主角”选择照片、姓名、年龄、班级和家人，保存后回书架。照片保留在当前浏览器，主动提交打印时才向本机后台发送生成的PDF。
4. 打开故事并翻阅至识字小结；在“我的”可继续阅读、查看阅读足迹和备份恢复。照片保留原始五官与发型，姓名不计入正文识字统计。
5. 进入“纸质绘本打印服务”选择第1级，核对15篇目录和人物设置，填写份数及配送信息、确认文件用途后提交。
6. 只有后台实际收到文件和订单才显示订单号。管理员在“打印订单”可下载PDF、处理需求、登记制作及交付。付款仍未接通，任何状态操作都不扣款、不自动向印厂下单。

静态4173预览不接收订单。不同端口有各自的浏览器资料，可通过“我的→导出本机备份／恢复”迁移。只选择备份不会覆盖资料，恢复须输入“恢复”确认。当前版本采用独立阅读记录键，旧版进度保留，避免把旧故事页码或已读标记套到新故事上。

## 当前打印范围

- 第1级15篇合订1册；第2—10级打印尚未开放。
- 默认三人家庭：99页正文、15页小结、1页目录、封面及封底，共117页。
- 家庭人数改变时页数、文字、插画和目录自动重算。测试四人家庭为100页正文、118页合集。
- 收件PDF为阅读顺序A5，成品148×210mm、四边3mm出血，文件154×216mm；中文字体嵌入、文字保持矢量。
- 制作人员仍可用 `?printTools=1` 下载A5无出血阅读校样或印厂包，普通用户流程不展示制作工具。
- 最终页面插画用JPEG质量0.90编码，300dpi画布不变，保存的头像和原生素材不改动。118页个性化测试文件为73.82MiB，低于浏览器96MiB和后台100MiB上限；不保证所有家庭组合与照片都同样大小，超限会明确停止而不会假提交成功。
- 输出仍是RGB校样，不代表完成实体打样、CMYK转换或PDF/X认证。

## 版本与运营数据

`current-edition.js` 共享清单驱动浏览器阅读和后台打印版本。新版合集商品为 `level-1-fifteen-v1`，启用前需自行填写价格；它不会继承旧 `level-1` 样册的价格。旧订单保持提交时快照，历史6篇接口保留兼容；版本、篇数或文件编号不匹配的订单会拒绝。

重复文件提交与重复建单按请求编号去重。账号鉴权、文件保存期限、联系资料清理和后台访问控制继续生效。当前真实登录与收款未开通；浏览器设备会话只用于本机试用与订单归属，不等于微信身份或跨设备同步。

## 还需要用户提供或决定的事项

当前本机完整试用不需要额外账号。先实际体验照片和翻页效果即可。后续对外上线时再决定或提供：

- 公网域名、服务器与部署账号；或者先继续同一局域网试用。
- 若首发包含微信：正式小程序AppID、云环境及平台配置授权。密钥只在服务端配置。
- 若开始收费：售价、运费、退款规则、发货时效与客服联系方式，以及商户账号。
- 印厂、纸张与装订选择，以及实物样书的颜色与清晰度确认。
- 正式运营主体和最终数据保存规则。

电脑浏览器尺寸模拟不是iPhone/Android真机验收。真实微信登录、在线支付、实体印刷不在本次本机试用完成范围内。
