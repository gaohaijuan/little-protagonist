# 家长阅读账号与本机资料

## 模块范围

`preview/account-functions.js` 通过现有的账号视图和事件入口注入浏览器预览，复用已有样式，不需要修改共享入口。浏览器的测试账号、昵称、引导和注销均明确标注为本机测试体验，不创建微信身份，不生成云端凭证。真实微信页面使用 `miniprogram/services/auth-service.js` 与 `cloudfunctions/account`；运营后台及另行封装的微信/抖音平台SDK保持原有边界。

首次微信注册后进入账号中心的引导卡片，家长称呼和孩子名字分别设置。孩子头像可稍后添加，游客阅读与跳过引导仍可使用；不增加内容权限或付费锁。小主角保存成功后，可在账号页完成引导并进入书架。

## 账号接口

客户端只通过 `getSnapshot()` 获取无凭证的身份视图。`user` 包含 `id`、`displayName`、`nickname`、`onboardingCompleted`、`accountVersion` 和 `createdAt`。

| 客户端方法 | 云函数操作 | 行为 |
| --- | --- | --- |
| `login({consent,reRegister})` | `login` | 首次自动注册；已注销账号须再次明确选择重新注册 |
| `restore()` | `session` | 验证当前微信身份、会话有效期和账号版本后恢复 |
| `updateAccountProfile(nickname)` | `update-profile` | 校验并保存家长称呼，不修改孩子资料 |
| `completeOnboarding()` | `complete-onboarding` | 保存引导完成状态，不上传孩子姓名或照片 |
| `logout()` | `logout` | 清除本机会话，并尝试撤销当前云端会话 |
| `closeAccount({confirmation:'注销'})` | `close-account` | 注销当前阅读账号，使该账号旧阅读会话失效 |

家长称呼去除首尾空白后须为1至16个Unicode码点，不接受换行、控制字符和方向控制字符。取消修改不提交草稿。昵称保存失败保留编辑内容，不能显示成功。元数据请求和注销请求互斥，账号切换或退出后的迟到响应不能恢复原账号。

账号标识仅由云函数中的可信微信上下文推导，不相信前端传入的账号归属。会话在云端仅保存随机凭证的摘要，并关联账号版本。元数据更新使用包含账号版本及状态的条件更新，不能重新创建已注销账号。

## 登录会话与失效

原生账号服务按云端返回的到期时间设置本地计时，同时在读取身份、更新资料、注销和带会话调用前后重新校验时间。后台暂停计时器或请求延迟不能让过期身份继续显示为已登录；失效时清除或标记无效的本机登录凭证、通知订阅页面，不删除任何孩子资料或阅读记录。过期前发出但过期后才返回的请求不能重新写回原身份，元数据响应中的用户或账号版本变化须重新登录确认。

登录和带会话云函数调用使用有限响应等待时间。超时登录若随后返回新凭证，会尝试撤销该迟到凭证，不撤销重试成功的新会话。网络失败恢复为离线状态时仍保留凭证供重试；主动退出可尝试撤销这份尚未恢复的凭证。无法读取旧凭证时只确认本机退出，不声称云端已撤销。注销须收到明确的 `closed:true`，不因含糊响应删除本机资料。

`createAuthService` 的第三个可选参数注入时钟及计时器，供测试精确验证到期边界、后台暂停与迟到响应；正式代码默认使用系统时间和计时器。此时间校验不能替代云端会话校验，正式微信注册与登录仍须真实AppID、云环境和真机联调。

## 账号版本与资料空间

账号版本由服务端随机生成。旧账号和旧会话缺少版本时兼容为 `legacy`，继续使用旧本机资料键；不能在升级时丢失原资料。新账号使用 `little-story.profile.v1:<userId>:<accountVersion>`，游客继续使用原来的 `little-story.profile.v1`。`getApp().getProfileStore()` 是各原生页面共用的入口，保存时校验账号及版本。

注销时云端清除家长称呼、引导状态和创建时间，并保存最小注销标记（派生账号ID、注销时间、随机版本和关闭状态），阻止旧登录请求恢复账号。旧会话因版本不符立即失效；失效摘要会尝试清理，数据库清理失败时仍不能继续认证，但记录可能保留至管理端清理。

重新注册须有明确的 `reRegister:true` 及当前说明版本，建立新的账号版本和本机资料空间。不能自动导入旧账号或其他设备上留存的孩子资料。重新导入游客资料仍需独立确认并复制头像文件。

## 孩子资料展示与游客导入

账号中心的“故事里的小主角”只展示已持久保存的姓名、年龄、班级和头像状态。没有保存过时显示设置提示，不把默认“小石头”当成用户已有资料；未保存的编辑草稿和取消的照片选择不能显示为已保存。浏览器另展示已保存家庭故事的出场人数，读取失败清除旧资料卡显示并提供重试。头像按原始比例完整显示，不重新生成人脸。

原生游客导入由 `services/guest-import.js` 准备只读快照。来源必须确实存在；确认框说明来源孩子、年龄班级、是否有照片，以及是否替换当前账号的孩子。只有确认后执行复制；游客原档和阅读记录不变，当前账号阅读记录保留且不复制游客阅读记录。浏览器测试账号继续沿用本机小主角，不虚设两个资料空间或另加导入按钮。

确认期间账号ID或版本变化、页面离开、来源资料变化，均不能提交旧确认。目标孩子在确认后发生编辑或从空白变成已保存时，保存队列内的比较也会要求重新确认，避免覆盖排队中的新编辑。头像复制为独立私有文件；复制或保存失败回收新文件，保留原档和目标原照片。成功后重新读取账号页资料卡，不通过成功提示代替真实保存结果。

`createProfileStore().loadProfile({strict:true})` 用于导入和资料卡读取，不将存储读取错误降级成默认资料；普通阅读仍沿用原来的容错读取。`saveProfile` 的 `expectedProfile` 与 `expectedHasProfile` 用于导入的目标比较，均在共享保存队列内校验。

运行 `node --test tests/guest-import.test.cjs tests/account-page.test.cjs tests/profile.test.cjs tests/account-data.test.cjs` 与 `npm run test:auth-browser` 验证导入、取消、来源缺失、排队编辑冲突、独立头像、存储错误、资料卡刷新和草稿取消。

## 本机备份与恢复

`lib/account-backup.js` 定义带格式与平台版本的JSON备份，浏览器使用既有构建入口注入的 `shared.accountBackup`。浏览器导出当前 `child/main` 中的姓名、年龄、班级、完整家庭成员、全部已保存PNG头像及位置度量，以及本机阅读记录；微信版通过 `services/account-backup.js` 导出当前资料空间的小主角、原头像文件和阅读记录。两种备份按平台分别恢复，不互相伪装支持家庭功能。导出内容不含家长身份、登录凭证、账号ID、服务器订单或原设备文件路径。

头像度量中的 `resolution` 兼容旧版正数与当前 `version:1, provenance:'original-photo-roi'` 结构。结构化格式保留源图尺寸、原始/保留/输出/有效脸部及头部像素、取样倍率、检测尺寸、遮罩尺寸和输出倍率的全部已知数值；拒绝缺失、非有限、非正或夸大有效原像素的资料。备份恢复不重新计算或提升PPI，浮点值与照片字节均保持原样。浏览器回归使用当前真实本地识别管线产生的头像及度量，不能仅用旧式测试小图证明兼容。

家长先阅读导出范围并主动生成/保存文件。浏览器文件用本机Blob生成，由家长点击下载；微信版由家长主动选择微信接收人（如文件传输助手），取消时不更改本机资料。备份未加密且可能包含真人照片，界面明确提示自行保管；不自动上传到本项目服务器或发给运营方。原生临时导出文件在保存/取消后尝试清理；实际设备上的文件选择、导出和清理结果仍须联调验证。

恢复仅接受不超过32MB的受支持JSON文件，校验孩子字段、家庭成员、图片数据、头像度量和阅读页码；拒绝网络图片地址、原设备路径与不兼容版本。浏览器读取所有备份图片后才展示预览；微信版将图片写入自建临时文件并通过图片信息接口验证，再复制到独立私有头像文件。头像字节与已有度量保持原样，不重绘、不压缩、不改脸、不重新取景。仅选择文件或取消预览不修改资料。

确认页列出备份孩子、当前被替换的小主角、照片和阅读记录范围，须输入“恢复”。恢复会替换当前本机资料空间；家长账号和其他空间保持原样。微信页离开/账号变化后的旧确认不能提交；排队中的孩子编辑、其他页面变更和阅读记录变化要求重新确认。浏览器孩子与家人记录采用同一IndexedDB事务替换；微信头像及孩子资料复用带比较条件的保存队列，失败回收新文件并保留旧资料。

孩子记录与阅读记录分开存储，不能声称跨存储原子恢复。如果孩子资料成功、阅读记录失败，分别显示实际结果，保留旧阅读记录，并提供只重试阅读记录的入口；重试不能重新覆盖之后修改过的孩子资料。关闭此面板不撤销已完成的孩子恢复。微信原生文件选择与文件导出仍须真机验证；接口依据 [微信官方API类型](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)。

运行 `node --test tests/account-backup.test.cjs tests/account-page.test.cjs tests/reading-store.test.cjs` 和 `node tests/account-backup.browser.cjs` 验证真实下载、照片字节/度量与家庭和进度往返、确认取消、格式错误、目标变化、写入失败与部分恢复重试。

## 本机阅读记录

原生通过 `getApp().getReadingStore()` 调用 `miniprogram/services/reading-store.js`，按与孩子资料相同的账号ID、账号版本隔离，游客有独立空间。记录只包含书籍ID、最近页码、总页数、曾经读完状态、本次是否已读完及更新时间，最多保留100本。读取时忽略失效书籍和非法页码；账号页根据当前孩子资料生成书名，不重复保存孩子姓名或照片。

阅读页打开时恢复未结束的最近页码；翻页、读完及重新阅读时同步保存。本次进度与历史完成状态分开，重读不会消除“曾读完”标记。存储失败显示提示，阅读和翻页继续可用，下一次翻页重试。账号变化后的旧阅读上下文不能写入其他资料空间；删除孩子资料同时清除当前空间阅读记录并使旧上下文失效。退出登录保留各自的本机记录，不提供跨设备同步。

浏览器在独立账号模块中观察已有翻页、键盘及滑动事件，不替换共享阅读事件处理器。记录使用 `little-story.preview-reading.v1`，沿用浏览器试用的共享小主角，退出或注销测试账号保留；明确删除本机孩子资料时一并清除。账号页提供“阅读足迹”与继续阅读入口，书架恢复已读标记。仅打开、翻页及完成记录不代表孩子已经认识或掌握书中汉字。

运行 `node --test tests/reading-store.test.cjs tests/account-page.test.cjs tests/account-data.test.cjs tests/native-ui.test.cjs` 和 `node tests/reading.browser.cjs` 验证恢复、重读、隔离、删除与存储失败恢复。

## 删除范围与失败恢复

原生账号页将两个操作分开：

- 删除本机孩子资料：仅删除当前资料空间内的姓名、年龄、班级和受该存储服务管理的头像，保留家长账号、其他账号与游客资料。确认页须输入“删除”。
- 注销阅读账号：确认页须输入“注销”。先注销云端阅读账号，成功后清理当前设备该账号的资料空间；云端失败不能直接清除本机资料。云端已注销但本机清理失败时分别说明结果，并提供重试。

删除队列与头像保存共用顺序。确认删除后，旧编辑器不能重新提交资料。只删除私有目录内符合 `hero-avatar-*` 命名规则的自有文件；不会清理相册或外部文件。清理头像失败时保存本机删除日志，账号页可再次发现已经确认删除、但尚未清理完成的文件。已有新资料的空间不参加后台清理；旧清理任务重试也不能删除新保存的小主角。

本次删除不包括其他设备的本机资料、已下载文件、已经主动提交给运营方的打印文件、运营账号或订单。运营数据及独立平台SDK的账号生命周期需由相应服务按其接口另行处理，不得把阅读账号注销描述成所有平台和业务记录已全部删除。

## 浏览器测试体验

测试状态保存在当前标签页的 `sessionStorage`（`little-story.preview-demo.v1`），最长12小时；家长称呼和引导完成状态独立保存在当前浏览器的 `localStorage`（`little-story.preview-account-profile.v1`）。退出测试保留称呼与引导状态，注销测试账号删除这些测试资料和当前测试状态；均不调用微信注册或注销接口。

浏览器测试沿用原有 IndexedDB 中 `child/main` 的小主角及家庭资料。注销测试账号保留这些借用资料。独立的“删除本机孩子资料”入口会在明确范围并输入“删除”后，原子删除这一条记录，重置当前页面资料、头像引用和阅读进度；不清空整个数据库，也不删除其他记录、其他网站、下载文件或运营方收件。

## 验证方式

运行 `node --test tests/auth.test.cjs tests/account-page.test.cjs tests/account-data.test.cjs` 验证账号生命周期、版本隔离、元数据校验、原生页面行为和资料删除失败重试。运行 `npm run test:auth-browser` 验证浏览器注册引导、昵称保存与取消、删除确认、注销测试体验、刷新恢复和版式。完整 `npm test` 也包含上述单元测试。

正式微信登录、云函数数据库行为和设备文件清理仍须在正式AppID、云环境与微信真机上联调。测试账号和模拟服务端通过不代表真实微信已开通，也不代表已完成正式注销验收。
